ORBIT — computer-use agent for the real Windows desktop
=======================================================

This is the product: a loop that
  1) photographs the real screen
  2) reads on-screen text (Windows OCR) and UI names
  3) decides the next click / type / open
  4) does it
  5) looks again
until the task is done or it has tried many paths.

HOW
- Keep Start-Orbit.bat + Orbit.ps1 together
- Double-click Start-Orbit.bat
- Click the orb → Talk or Text
- Allow screen/cursor access once

TRY
- open chrome go to youtube and search Shape of You
- open canva and create a new project
- click Create
- type Hello world

It is built to keep going, not to stop after one guess.
Login walls (Google/Canva) still need you to sign in once — after that
Orbit can click the named buttons it can see.

Quit: tray icon → Quit Orbit
Windows 10/11. No Node required.
